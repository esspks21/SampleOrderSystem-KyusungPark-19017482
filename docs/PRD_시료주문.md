# PRD - 시료 주문

## 개요

고객이 시료를 요청하면 주문담당자가 주문서를 등록·관리합니다.
접수된 주문은 `RESERVED` 상태로 시작하며, 이후 담당자 처리를 통해 상태가 전이됩니다.

## 주문 속성

| 속성 | 설명 |
|------|------|
| 주문 ID | 주문을 고유하게 식별하는 값 |
| 고객명 | 주문을 요청한 고객 이름 |
| 시료 ID | 주문 대상 시료 |
| 수량 | 요청 수량 |
| 상태 | 현재 주문 상태 |

## 기능 요구사항

| ID | 메뉴 | 요구사항 |
|----|------|----------|
| F-O01 | 주문 접수 | 고객명, 시료, 수량을 입력하여 주문을 생성하고 `RESERVED` 상태로 접수한다. |
| F-O02 | 주문 목록 조회 | 전체 주문 목록을 상태와 함께 표시한다. |
| F-O03 | 주문 상세 조회 | 특정 주문의 상세 정보를 확인한다. |
| F-O04 | 주문 취소 | `RESERVED` 또는 `PENDING` 상태의 주문을 취소하고 `CANCELLED`로 전환한다. |

## 주문 상태 정의

| 상태 | 의미 |
|------|------|
| `RESERVED` | 고객 예약 완료, 주문담당자 접수 대기 중 |
| `PENDING` | 주문담당자 접수 완료, 생산담당자 승인 대기 중 |
| `CONFIRMED` | 생산담당자 승인 완료, 생산 큐 대기 중 |
| `PRODUCING` | 생산 라인에서 생산 진행 중 |
| `RELEASE` | 출고 완료 |
| `REJECTED` | 생산담당자 거절 (모니터링 집계 제외) |
| `CANCELLED` | 주문 취소 (`RESERVED` / `PENDING` 단계에서만 가능) |

## 주문 상태 전이

```
RESERVED → PENDING → CONFIRMED → PRODUCING → RELEASE
                   → REJECTED
         → CANCELLED  (RESERVED / PENDING 단계에서만 가능)
```
