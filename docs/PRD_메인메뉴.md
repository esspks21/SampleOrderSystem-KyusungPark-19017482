# PRD - 메인메뉴

## 개요

콘솔 애플리케이션 실행 시 최초로 표시되는 화면으로, 전체 시료 요약 정보와 기능 메뉴를 함께 제공합니다.

## 화면 구성

메인 화면은 두 영역으로 구성됩니다.

1. **전체 시료 요약 정보** — 현재 등록된 시료 수, 주문 현황(대기/확정/출고 등) 집계를 상단에 표시
2. **메뉴 선택** — 기능별 번호를 입력하여 해당 화면으로 이동

```
============================================
  반도체 시료 생산주문관리 시스템
============================================
[시료 요약]
  등록 시료: N개  |  대기 주문: N건  |  확정 주문: N건  |  출고 완료: N건

--------------------------------------------
1. 시료 관리
2. 주문 (접수 / 승인 / 거절)
3. 모니터링
4. 출고 처리
5. 생산 라인
0. 종료
--------------------------------------------
선택 >
```

## 기능 요구사항

| ID | 요구사항 |
|----|----------|
| F-M01 | 메인 화면 상단에 등록 시료 수, 대기·확정·출고 주문 건수를 요약 표시한다. |
| F-M02 | 콘솔 메뉴를 통해 모든 기능 영역에 접근할 수 있다. |
| F-M03 | 잘못된 입력에 대해 오류 메시지를 출력하고 재입력을 요청한다. |
| F-M04 | 0 입력 시 프로그램을 종료한다. |
