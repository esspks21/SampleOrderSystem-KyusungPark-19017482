# PRD - 모니터링

## 개요

주문 및 생산·재고 현황을 한눈에 파악할 수 있는 대시보드입니다.
`REJECTED`와 `CANCELLED`는 정상 흐름 외의 상태로 모니터링에서 제외합니다.

## 모니터링 대상 상태

| 상태 | 포함 여부 | 설명 |
|------|----------|------|
| `RESERVED` | 포함 | 고객 예약 완료, 접수 대기 중 |
| `PENDING` | 포함 | 주문담당자 접수 완료, 승인 대기 중 |
| `CONFIRMED` | 포함 | 생산 승인 완료, 생산 큐 대기 중 |
| `PRODUCING` | 포함 | 생산 라인에서 생산 진행 중 |
| `RELEASE` | 포함 | 출고 완료 |
| `REJECTED` | **제외** | 거절된 주문 |
| `CANCELLED` | **제외** | 취소된 주문 |

## 기능 요구사항

| ID | 메뉴 | 요구사항 |
|----|------|----------|
| F-MN01 | 주문량 확인 | `REJECTED`·`CANCELLED`를 제외한 유효 주문의 상태별 목록을 표시한다. |
| F-MN02 | 재고량 확인 | 시료별 현재 재고 수량과 주문 대비 재고 상태를 함께 표시한다. |
| F-MN03 | 생산 현황 | 현재 `PRODUCING` 상태인 주문의 생산 진행 정보를 표시한다. |

## 재고 상태 기준

| 재고 상태 | 기준 |
|-----------|------|
| 여유 | 주문 대비 재고 충분 |
| 부족 | 주문 대비 재고 수량 부족 |
| 고갈 | 재고 수량이 0 |
