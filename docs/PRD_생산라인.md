# PRD - 생산라인

## 개요

생산라인 정보를 조회하고, 생산 중인 시료 현황 및 대기 중인 작업 목록을 확인합니다.
하나의 생산 라인은 시료를 하나씩 순차 생산하며, 주문이 들어온 시료에 대해서만 생산을 진행합니다.

## 생산량 계산

| 항목 | 공식 |
|------|------|
| 실 생산량 | `ceil(부족분 / (수율 × 0.9))` |
| 총 생산시간 | `평균 생산시간 × 실 생산량` |

> 수율과 오차(×0.9)를 고려하여 실제 필요 수량보다 넉넉하게 생산합니다.
> 생산 완료 시 주문 상태를 `PRODUCING` → `CONFIRMED`으로 전환합니다.

## 스케줄링 전략

**FIFO** — 먼저 접수된 생산 작업이 먼저 처리됩니다.

## 기능 요구사항

| ID | 메뉴 | 요구사항 |
|----|------|----------|
| F-P01 | 생산 현황 표기 | 현재 생산 중인 시료의 주문 정보, 현재까지의 생산량 등을 표시한다. |
| F-P02 | 대기 주문 확인 | 생산 큐에서 대기 중인 작업 목록을 FIFO 순서로 출력한다. |
