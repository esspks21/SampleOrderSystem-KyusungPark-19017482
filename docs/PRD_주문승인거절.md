# PRD - 주문 승인/거절

## 개요

주문담당자가 `RESERVED` 주문을 `PENDING`으로 접수하고,
생산담당자가 `PENDING` 주문을 검토하여 승인 또는 거절을 처리합니다.

## 기능 요구사항

| ID | 메뉴 | 요구사항 |
|----|------|----------|
| F-A01 | 접수된 주문 목록 | `RESERVED` 상태의 주문 목록을 표시한다. |
| F-A02 | 주문 접수 | 주문담당자가 `RESERVED` 주문을 확인 후 접수 → `PENDING`으로 전환한다. |
| F-A03 | 주문 승인 | 생산담당자가 `PENDING` 주문을 승인하며, 재고 상황에 따라 자동 처리한다. |
| F-A04 | 주문 거절 | 생산담당자가 `PENDING` 주문을 거절하고 즉시 `REJECTED` 상태로 전환한다. |

## 주문 승인 상세 처리

| 조건 | 처리 |
|------|------|
| 재고 충분 | 주문을 즉시 `CONFIRMED` 상태로 전환 |
| 재고 부족 | 생산 라인에 자동 등록, 주문 상태를 `PRODUCING`으로 전환 |
