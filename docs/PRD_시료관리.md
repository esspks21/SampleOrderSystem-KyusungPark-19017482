# PRD - 시료 관리

## 개요

시료(Sample)는 이 시스템의 가장 기본이 되는 단위입니다.
각 시료는 고유한 이름과 속성을 가지며, 시스템에 등록된 시료만 주문 가능합니다.

## 시료 속성

| 속성 | 설명 |
|------|------|
| 시료 ID | 시료를 고유하게 식별하는 값 |
| 이름 | 시료명 |
| 평균 생산시간 | 시료 1개를 생산하는 데 걸리는 평균 시간 |
| 수율 | 정상적인 시료 수 / 총 생산 시료 수 (예: 100개 생산 중 90개 정상 → 0.9) |

## 기능 요구사항

| ID | 메뉴 | 요구사항 |
|----|------|----------|
| F-S01 | 시료 등록 | 새로운 시료를 시스템에 추가한다 (시료 ID, 이름, 평균 생산시간, 수율). |
| F-S02 | 시료 조회 | 등록된 모든 시료 목록을 현재 재고 수량과 함께 확인한다. |
| F-S03 | 시료 검색 | 이름 등 속성으로 특정 시료를 검색한다. |
