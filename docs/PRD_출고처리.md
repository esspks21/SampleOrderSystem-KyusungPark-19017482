# PRD - 출고 처리

## 개요

출고 대기 중인 주문(CONFIRMED)을 확인하고 출고를 완료합니다.
출고 완료 시 주문 상태를 `CONFIRMED` → `RELEASE`로 전환합니다.

## 기능 요구사항

| ID | 메뉴 | 요구사항 |
|----|------|----------|
| F-R01 | 출고 대기 목록 | CONFIRMED 상태의 주문 목록을 표시한다. |
| F-R02 | 출고 처리 | 특정 주문을 출고 완료 처리하고 상태를 RELEASE로 전환한다. |
| F-R03 | 출고 내역 조회 | RELEASE 상태의 완료된 출고 내역을 조회한다. |
